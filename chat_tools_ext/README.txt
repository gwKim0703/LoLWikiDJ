롤디칩 (lolDChip) v1.1.1

설치 방법
1. ZIP 압축 해제
2. chrome://extensions 또는 edge://extensions 열기
3. 개발자 모드 활성화
4. "압축해제된 확장 프로그램을 로드합니다" 선택
5. 이 폴더를 선택

기능

[멘션]
- @ 입력 시 참가자 드롭다운 표시 (아이콘 + 닉네임)
- /vol 입력 시에도 동일한 드롭다운 표시 (입력 시작 부분에서만 작동)
- 화살표, Tab, Enter, PgUp, PgDn, Home, End 키로 탐색 및 선택

[답장]
- 채팅 말풍선의 ↩ 버튼으로 답장 대상 선택
- 확장 사용자끼리 공유되는 reply marker (⟦r:key⟧) 파싱 및 회색 말풍선 표시
- reply 말풍선 클릭 시 원본 메시지로 스크롤 이동
- GIF/이미지 답장 시 [이미지] 텍스트로 표시

[채팅 히스토리]
- 화살표 위/아래 키로 이전 채팅 내역 탐색 (최대 50개)
- 답장 마커는 히스토리에서 제외

[프로필]
- 팝업에서 로그인 기록 확인 (접속 중 표시)
- 프로필 간 계정 전환 및 삭제

[라이브챗 차단]
- 팝업 체크박스로 YouTube 라이브챗 표시/숨김 전환

[쪽지함]
- 설정 메뉴에 쪽지함 버튼 추가
- 클릭 시 팝업 창에서 쪽지함 열기
- (신버전 대응 모드에서는 쪽지함 버튼 대신 헤더의 '알림센터'로 대체 — 아래 참고)

[자유게시판 신버전 대응 (신 서버 연동)]
- 팝업 '설정'의 체크박스로 켜고 끔 (기본 켜짐)
- 롤백과사전 앱과 동일한 신규 REST API로 자유게시판을 연동
  (구 통신 게시판이 읽기전용으로 전환된 것에 대응)
- 신 서버 계정 로그인/로그아웃 지원 (구 통신 로그인 대체용 자체 로그인 창 제공)
- 글/댓글 작성을 신 서버로 전송 (앱과 동일하게 표시)
- 내가 쓴 글/댓글에 삭제 버튼 표시 및 삭제
- 댓글 '답글' 기능: 답글 UI/들여쓰기 표시, 답글 작성
  · 답글 시 입력창이 해당 댓글 바로 아래로 이동
  · '@닉네임' 자동 태그 삽입 및 표시된 멘션 강조(파란색)
- 시간 표기 개선: now(3초 이내) / N초전 / N분전 / HH:MM(당일) / YYYY-MM-DD(이전),
  경과 구간별 색상 구분과 볼드 처리(DJ 사이트 라이트/다크 테마에 맞춰 색 적용)
- 알림센터: 헤더에 🔔 아이콘 추가, '알림'과 '채팅(쪽지)' 탭 제공
  · 채팅 탭에서 대화 내역 확인 및 답장, 상대 아이콘/날짜 구분 표시
  · 대화 상세에서 상단 헤더(뒤로가기·닉네임)와 입력창 고정, 메시지 영역만 스크롤
  · DJ 사이트의 라이트/다크 테마 설정에 맞춰 알림센터 색상 자동 적용
- 이미지 공유: 글/댓글/유저 아이콘 이미지(gif·webp 등)를
  · 공유 버튼으로 채팅에 공유 (글쓴이 아이콘 포함 정상 표시)
  · 채팅창으로 끌어놓기(드래그)로도 공유 — 모든 사용자에게 실제 이미지로 보임
- 유저 차단: 모바일 앱에서 차단한 유저의 글/댓글을 숨김(앱과 차단 목록 공유)
  · 글 상세의 '[차단하기]' 버튼으로 확장에서도 차단 → 앱 차단 목록에도 반영
  · 차단 해제는 앱의 '내 정보 → 차단목록'에서

[볼륨 메모리]
- 영상 볼륨 및 음소거 상태를 도메인별로 자동 저장
- 새로고침·재접속 시 마지막 설정한 볼륨으로 자동 복원

[프로필 아이콘 대체]
- 자유게시판 프로필 아이콘을 기본 이미지로 먼저 표시
- 실제 아이콘은 백그라운드에서 로드 성공했을 때만 교체 (엑박/투명 방지)

[자유게시판 컴팩트 모드]
- 팝업 '설정'의 체크박스로 켜고 끔 (기본 꺼짐)
- 자유게시판의 '글 목록'과 '글 내용'을 왼쪽 한 컬럼(485px)으로 합침
  (목록에서 글을 좌클릭하면 같은 자리에서 글 내용으로 전환)
- 남는 오른쪽 공간으로 DJ 영상을 축소·이동시켜, 자유게시판을 열어둔 채로
  영상 시청과 채팅을 동시에 할 수 있음 (배치: [자유게시판 | 영상 | 채팅])
- 글 내용에서 목록으로 복귀:
  · 헤더 우측 하단('차단하기' 우측·새로고침 버튼 아래)의 '← 목록' 버튼
  · 내용 영역 우클릭 (이미지/영상/링크/입력창 위, 텍스트 선택 중엔 평소 우클릭 유지)
- 글 내용에서 닉네임 우클릭 시 작성자 글 목록 보기(목록 뷰로 전환)
- 목록 ⇄ 내용/글쓰기 전환 및 영상 축소·이동에 방향에 맞춘 슬라이드 애니메이션 적용
- 글쓰기(취소 버튼으로 복귀) / 아이콘 제작도 같은 컬럼에서 처리
- 북마크/명예의전당 목록에서 글 우클릭 시의 아카이브 스냅샷도 지원

[새로고침·뒤로가기 이탈 확인]
- 팝업 '설정'의 체크박스로 켜고 끔 (기본 켜짐)
- 새로고침(F5)·뒤로가기·탭 닫기 시 브라우저 이탈 확인창을 한 번 표시
  → 실수로 DJ 세션이 종료되는 것을 방지 (확인 시 정상 이동, 취소 시 유지)

[다크/라이트 테마 자동 대응]
- 확장이 추가하는 UI(멘션 드롭다운, 답장 표시줄, 알림센터, 댓글 멘션 강조 등)를
  DJ 사이트의 라이트/다크 테마 설정에 맞춰 색상 자동 전환

주의
- 확장은 lolwiki.xyz 도메인에서만 작동합니다.
- reply 공유 방식은 메시지 본문 앞에 짧은 marker를 붙이는 방식입니다.
- 확장 프로그램이 없는 사용자는 marker 문자열을 볼 수 있습니다.
- 쪽지함은 자유게시판 로그인(android_id)이 필요합니다.

[수정] 자유게시판 이미지 공유(공유 버튼) 시 글쓴이 아이콘이 흰색으로 보이던 문제
  - 공유 카드에 실제 글쓴이 아이콘이 표시되도록 수정
[수정] 자유게시판 이미지 드래그 공유 복구
  - 신버전 대응 모드에서 글/댓글/유저 아이콘 이미지(gif·webp 포함)를
    채팅창으로 끌어놓아 공유하는 기능이 동작하지 않던 문제 수정
  - 자유게시판 이미지를 DJ 서버 미러(동일 출처) 경유로 표시하도록 변경하여
    표시·드래그 공유·공유 아이콘이 모든 사용자에게 정상 동작
    (Referer 핫링크 보호로 인한 'BG.GG 접속 시 확인 가능' 안내 이미지 노출도 해소)
[수정] 글/댓글 시각 표기 색상 개선 (테마별 대응)
  - 작성 3초 이내는 'now'로 표기
  - 경과 구간별 색을 DJ 사이트 라이트/다크 테마에 맞춰 적용
    · now      라이트 #E53935 / 다크 #EF5350
    · N초 전   라이트 #501C60 / 다크 #CE93D8
    · N분 전·HH:MM  라이트 #8C3A38 / 다크 #964B53
    · 날짜     회색 공통
  - 볼드 유지하며 한 단계 더 굵게(font-weight 800)
[수정] 알림센터 배지 숫자가 알림 확인 후에도 한동안(최대 60초) 남던 문제
  - 알림 클릭 시 배지를 즉시 감소(낙관적 반영)하고,
    읽음 처리 완료를 기다린 뒤 서버값으로 재계산하도록 수정
    (기존에는 읽음 커밋 전 옛 미확인 수를 다시 받아와 배지가 늦게 갱신됨)
[수정] 자유게시판 글 상세 로딩 개선
  - 로딩이 느린 옛 글(대용량 이미지 포함)을 누른 뒤 다른 글을 눌렀을 때,
    나중에 도착한 이전 글 내용이 현재 보는 글을 덮어쓰던 문제 수정(세대 토큰으로 폐기)
  - 제목·내용을 먼저 표시하고 댓글은 준비되는 대로 채우도록 변경
    (일부 옛 이미지 글은 서버가 댓글 응답을 만드는 데 수 초 걸려도 본문은 즉시 표시)
    · 댓글이 늦으면 댓글 영역에 '댓글 불러오는 중…' 표시, 빠르면 본문·댓글 한 번에 렌더
    · 이미지는 그 뒤 비동기 로드 — 본문·댓글 표시를 막지 않음
  - 글 클릭 즉시 '불러오는 중…' 표시로 반응성 개선
