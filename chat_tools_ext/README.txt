롤디칩 (lolDChip) v1.2.0

설치 방법
1. ZIP 압축 해제
2. chrome://extensions 또는 edge://extensions 열기
3. 개발자 모드 활성화
4. "압축해제된 확장 프로그램을 로드합니다" 선택
5. 이 폴더를 선택

기능

[멘션]
- @ 입력 시 참가자 드롭다운 표시 (아이콘 + 닉네임)
- /vol 입력 시에도 동일한 드롭다운 표시 (입력 시작 부분에서만 작동)
- 화살표, Tab, Enter, PgUp, PgDn, Home, End 키로 탐색 및 선택

[답장]
- 채팅 말풍선의 ↩ 버튼으로 답장 대상 선택
- 확장 사용자끼리 공유되는 reply marker (⟦r:key⟧) 파싱 및 회색 말풍선 표시
- reply 말풍선 클릭 시 원본 메시지로 스크롤 이동
- GIF/이미지 답장 시 [이미지] 텍스트로 표시

[채팅 히스토리]
- 화살표 위/아래 키로 이전 채팅 내역 탐색 (최대 50개)
- 답장 마커는 히스토리에서 제외

[프로필]
- 팝업에서 로그인 기록 확인 (접속 중 표시)
- 프로필 간 계정 전환 및 삭제

[라이브챗 차단]
- 팝업 체크박스로 YouTube 라이브챗 표시/숨김 전환

[쪽지함]
- 설정 메뉴에 쪽지함 버튼 추가
- 클릭 시 팝업 창에서 쪽지함 열기
- (DJ 사이트에 알림센터가 생기기 전까지는 헤더의 '알림센터'로 대체 — 아래 참고)

[자유게시판 보조 기능]
※ 자유게시판 자체(목록·글·댓글 조회, 글/댓글 작성과 이미지 첨부, 삭제, 유저 차단)는
   DJ 사이트가 신 API로 직접 처리합니다. 확장은 사이트에 아직 없는 것만 보강합니다.
   설정 체크박스 없이 항상 동작하며, 확장 전용 로그인 창도 없습니다
   (사이트 로그인에 편승해 확장도 자동으로 인증합니다).
- 시간 표기 개선: now(3초 이내) / N초전 / N분전 / N시간전(12시간 미만) /
  HH:MM(당일) / YYYY-MM-DD(그 외),
  경과 구간별 색상 구분과 볼드 처리(DJ 사이트 라이트/다크 테마에 맞춰 색 적용)
  · 12시간 미만이면 자정을 넘겨 날짜가 바뀌어도 경과시간으로 표시
    (예: 27일 00:30에 보는 26일 19:30 글 → '5시간전')
  · 글·댓글 모두 마우스를 올리면 정확한 날짜·시각 표시
  · 화면을 다시 그릴 때마다 다시 계산해, 페이지를 열어둬도 표기가 멈추지 않음
- 댓글 '답글': 사이트는 답글을 지원하지 않아(작성 시 항상 일반 댓글) 확장이 보강
  · 앱에서 달린 답글을 부모 댓글 아래로 정렬하고 들여쓰기로 표시
  · 각 댓글의 '답글' 버튼으로 답글 작성 (입력창이 해당 댓글 아래로 이동)
  · 답글에도 이미지 첨부 가능, 등록 시 '@닉네임' 자동 삽입, 멘션 강조(파란색)
  · 일반 댓글은 그대로 사이트가 처리
- GIF/WebP 원본 유지: 사이트는 이미지를 JPEG로 변환해 움직이는 이미지가 정지되는데,
  붙여넣거나 끌어놓은 원본을 그대로 올려 움직이는 상태로 등록
  · 댓글·답글: GIF·WebP 모두 원본 유지
  · 글쓰기: WebP 원본 유지 (GIF는 사이트가 이미 지원)
- 닉네임 우클릭 → 작성자 글 목록: 서버 경로가 옛 방식이라 동작하지 않던 것을 확장이 대체
- 닉네임 변경: 변경 전 '24시간 동안 재변경 불가' 경고를 표시하고,
  변경이 거부되면(24시간 제한 등) 서버가 알려주는 실제 사유를 팝업으로 안내
- 글 상세 로딩 표시: 글 클릭 즉시 '불러오는 중…' 표시(이미지가 큰 글에서 무반응 체감 제거)
- 내 글 삭제 후 즉시 반영: 사이트는 안내창만 띄우고 화면을 갱신하지 않아 삭제한 글이
  그대로 남아 보이던 것을, 확인을 누르면 상세를 비우고 목록에서도 바로 사라지도록 처리
- 게시글 추천/비추천: 사이트가 아직 추천만 지원 → 상세에서 비추천(▼)과 취소까지 지원
  · 추천 0인 글은 비추천 불가, 1 이상이면 둘 다 가능, 같은 버튼 재클릭으로 취소
  · 투표 후 서버 실제값을 재조회해 추천 수·내 상태를 정확히 반영
- 좌측 상단 내 프로필 아이콘을 새로고침 시 최신값으로 갱신
  (다른 앱에서 아이콘 변경 시에도 게시판 새로고침으로 즉시 반영)
- 내 글/댓글 판정 보정: 레거시 계정(작성자 ID가 UUID 형식)의 글에서 '삭제' 버튼이
  보이지 않던 문제 보정 (사이트는 작성자 ID를 한 가지 키로만 비교)
- 고정짤 등록/삭제: 설정 메뉴(프로필 아이콘 클릭)의 '아이콘 제작' 바로 아래에 버튼 추가
  · '고정짤 등록' 창에서 이미지를 복사한 뒤 Ctrl+V 로 붙여넣고 [등록]
  · 신 API의 프로필 고정짤(fixed_image_id)로 저장되어 앱에도 동일하게 적용
  · '고정짤 삭제'로 해제
- 유저 차단: 글 상세의 '[차단하기]' 버튼 (사이트는 아직 미구현이라 확장이 담당)
  · 차단하면 그 사용자의 글·댓글이 즉시 숨겨지고, 앱 차단 목록에도 함께 반영
  · 자기 글에서는 버튼이 표시되지 않음
- 차단목록: 설정 메뉴의 '차단목록'(구 '차단목록 초기화' — 사이트 미구현이라 확장이 대체)
  · 내가 차단한 사용자 목록을 아이콘·닉네임·차단 시각과 함께 표시
  · 개별 '해제'와 '전체 해제' 지원 (앱의 '내 정보 → 차단 관리'와 같은 목록을 공유)
- 알림센터: 헤더에 🔔 아이콘 추가, '알림'과 '채팅(쪽지)' 탭 제공
  · 채팅 탭에서 대화 내역 확인 및 답장, 상대 아이콘/날짜 구분 표시
  · 대화 상세에서 상단 헤더(뒤로가기·닉네임)와 입력창 고정, 메시지 영역만 스크롤
  · DJ 사이트의 라이트/다크 테마 설정에 맞춰 알림센터 색상 자동 적용

[볼륨 메모리]
- 영상 볼륨 및 음소거 상태를 도메인별로 자동 저장
- 새로고침·재접속 시 마지막 설정한 볼륨으로 자동 복원

[프로필 아이콘 대체]
- 자유게시판 프로필 아이콘을 기본 이미지로 먼저 표시
- 실제 아이콘은 백그라운드에서 로드 성공했을 때만 교체 (엑박/투명 방지)

[자유게시판 컴팩트 모드]
- 팝업 '설정'의 체크박스로 켜고 끔 (기본 꺼짐)
- 자유게시판의 '글 목록'과 '글 내용'을 왼쪽 한 컬럼(485px)으로 합침
  (목록에서 글을 좌클릭하면 같은 자리에서 글 내용으로 전환)
- 남는 오른쪽 공간으로 DJ 영상을 축소·이동시켜, 자유게시판을 열어둔 채로
  영상 시청과 채팅을 동시에 할 수 있음 (배치: [자유게시판 | 영상 | 채팅])
- 글 내용에서 목록으로 복귀:
  · 헤더 우측 하단('차단하기' 우측·새로고침 버튼 아래)의 '← 목록' 버튼
  · 내용 영역 우클릭 (이미지/영상/링크/입력창 위, 텍스트 선택 중엔 평소 우클릭 유지)
- 글 내용에서 닉네임 우클릭 시 작성자 글 목록 보기(목록 뷰로 전환)
- 목록 ⇄ 내용/글쓰기 전환 및 영상 축소·이동에 방향에 맞춘 슬라이드 애니메이션 적용
- 글쓰기(취소 버튼으로 복귀) / 아이콘 제작도 같은 컬럼에서 처리
  · 아이콘 제작의 '취소'는 선택한 이미지만 지움(창은 유지) — 나가려면 '← 목록' 또는 우클릭
  · 글쓰기·아이콘 제작을 완료하면 목록으로 돌아오며, 직전 글이 다시 열리지 않음
- 북마크/명예의전당 목록에서 글 우클릭 시의 아카이브 스냅샷도 지원

[새로고침·뒤로가기 이탈 확인]
- 팝업 '설정'의 체크박스로 켜고 끔 (기본 켜짐)
- 새로고침(F5)·뒤로가기·탭 닫기 시 브라우저 이탈 확인창을 한 번 표시
  → 실수로 DJ 세션이 종료되는 것을 방지 (확인 시 정상 이동, 취소 시 유지)

[다크/라이트 테마 자동 대응]
- 확장이 추가하는 UI(멘션 드롭다운, 답장 표시줄, 알림센터, 댓글 멘션 강조 등)를
  DJ 사이트의 라이트/다크 테마 설정에 맞춰 색상 자동 전환

주의
- 확장은 lolwiki.xyz 도메인에서만 작동합니다.
- reply 공유 방식은 메시지 본문 앞에 짧은 marker를 붙이는 방식입니다.
- 확장 프로그램이 없는 사용자는 marker 문자열을 볼 수 있습니다.
- 쪽지함은 자유게시판 로그인(android_id)이 필요합니다.


========================================
변경 이력 (버전별 추가/수정 사항)
========================================

v1.2.0
[정리] DJ 사이트가 자유게시판을 신 API에 직접 대응 → 중복 기능 폐기
  - '자유게시판 신버전 대응' 폐기: 목록·글·댓글 조회와 글/댓글 작성·삭제를
    확장이 대신 처리하지 않고 사이트에 맡김 (팝업의 해당 체크박스도 제거)
    · 이제 사이트가 처리하므로 글·댓글에 이미지 첨부가 정상 동작
  - 확장 전용 로그인 창 폐기: 사이트 로그인에 편승해 확장도 자동 인증
    (알림센터·추천/비추천·프로필 갱신에 필요한 인증을 별도 로그인 없이 확보)
  - 유저 차단 연동 폐기 (사이트가 자체 지원)
  - 자유게시판 이미지 채팅 공유(공유 버튼·드래그) 폐기 (사이트가 자체 지원)
[유지] 댓글 '답글' — 사이트가 아직 지원하지 않아 확장이 계속 담당
  - 계층(들여쓰기) 표시와 '답글' 버튼, 답글 작성 모두 유지
  - 답글에도 이미지 첨부 지원 (일반 댓글은 사이트가 처리)
[복원] 고정짤 등록/삭제 (신 서버 방식으로 재구현)
  - 이미지 업로드가 가능해져(아래 참고) 신 API 프로필의 고정짤로 등록하도록 복원
  - 설정 메뉴의 '고정짤 등록' 창에 이미지를 붙여넣기(Ctrl+V) → [등록], '고정짤 삭제'로 해제
  - 버튼 위치는 설정 메뉴의 '아이콘 제작' 바로 아래
[수정] GIF·WebP를 첨부해도 움직이지 않던 문제
  - 사이트는 첨부 이미지를 캔버스로 JPEG 변환(첫 프레임만)해 움직이는 이미지가 정지되던 문제
    · 댓글: GIF·WebP 모두 변환됨 (형식 정보도 보내지 않음)
    · 글쓰기: GIF는 원본을 보내지만 WebP는 변환됨
  - 붙여넣기·끌어놓기 시점에 원본을 따로 보관해, 등록할 때 원본 형식 그대로 업로드하도록 수정
[수정] 컴팩트 모드에서 아이콘 제작 관련 두 가지 문제
  - 아이콘 등록을 완료하면 목록으로 돌아오는 동시에 직전에 보던 글이 다시 열리던 문제
    (완료 처리 중 글 내용이 되돌아오는 것을 '글 열림'으로 오인하던 것을 수정)
  - 아이콘 등록 창에서 '취소'를 누르면 선택한 이미지만 지워져야 하는데
    창 자체가 목록으로 빠져나가던 문제 수정 (이제 이미지만 초기화하고 창 유지)
[수정] 닉네임 변경이 거부돼도 아무 안내 없이 끝나던 문제
  - 닉네임은 한 번 바꾸면 24시간 동안 다시 바꿀 수 없는데, 제한에 걸려 거부되면
    서버가 이를 실패로 전달하지 못해 '확인은 됐지만 바뀌지 않은' 상태로 보이던 문제
  - 확장이 변경을 직접 처리해 서버가 알려주는 실제 사유를 팝업으로 표시
  - 변경 전에도 '24시간 동안 다시 변경할 수 없음'을 확인창과 입력창에서 안내
[복원] 닉네임 우클릭 시 그 작성자의 글 목록 보기
  - 서버가 '내 글' 방식으로 조회하면서 작성자 조건이 무시돼 결과가 비던 문제
    (작성자 조건만 쓰면 정상인데, 서버가 '내 글' 표시를 함께 보내 조건이 상쇄됨)
  - 사이트가 정상 지원하는 닉네임 검색 경로로 같은 목록을 얻도록 대체
    (조회 자체는 그대로 사이트·서버가 수행, 스크롤 추가 로딩에서도 필터 유지)
[수정] 글 목록에서 시간이 제목보다 한 칸 밀려 보이던 문제
  - 시각 값 앞에 공백이 섞여 오면 서식화를 건너뛰어 '공백+날짜'로 보이던 것 수정(앞뒤 공백 제거)
